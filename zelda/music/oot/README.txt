Music for ambient_zmusic / zmus_play goes here.

  .miniusf / .usf (+ the .usflib they reference): played by lazyusf2, the N64 sound driver
                    emulated. Use the USF rip of YOUR copy of Ocarina of Time.
  .wav            : played as is (any sample rate, mono or stereo PCM).

Example: zmus_play music/oot/kokiri_forest.miniusf 2
The test map plays music/oot/test.miniusf if it exists.
These files are git ignored; don't commit them.
