// Zelda 64 port: message box text.
//
// @NAME [BLACK|WOODEN|BLUE|NONE] [VARIABLE|TOP|MIDDLE|BOTTOM]
// Text follows until the next @ line. Keep lines to about 26 characters and boxes to 4 lines,
// like the N64 game. NAME#1, NAME#2... make a pool that is picked from at random.
//
// Codes (same meaning as the decomp's message_data_fmt.h macros):
//   {BOX} next box        {BOX:n} next box after n frames      {FADE:n} close after n frames
//   {RED} {GREEN} {BLUE} {LIGHTBLUE} {PURPLE} {YELLOW} {BLACK} {WHITE}
//   {NAME} player name    {SHIFT:n}   {INSTANT} ... {/INSTANT}   {SPEED:n}   {WAIT}
//   {CHOICE2} {CHOICE3}   the last 2 / 3 lines of the box are the options (first = yes)
//   {SFX:NA_SE_SY_...}    play a sound from pm_shared/zl_sounds.h
//   {UNSKIPPABLE}
//
// The game asks for these names:
//   SC_IDLE, SC_FOLLOW_ASK, SC_STAY_ASK       scientists
//   BA_IDLE, BA_FOLLOW_ASK, BA_STAY_ASK       security guards
//   NPC_IDLE                                  anything else with no "message" key set
//   ITEM_*                                    item get boxes (dlls/zl_items.cpp)
// Mappers can put any name here in a monster's / trigger_zmessage's / zl_sign's "message" key.

@ZL_TEST BLACK BOTTOM
Hey! {NAME}! Listen!
This is the {RED}message box{WHITE} from
{LIGHTBLUE}Ocarina of Time{WHITE}, running in
{YELLOW}Half-Life{WHITE}.
{BOX}
Colours: {RED}red {GREEN}green {BLUE}blue
{LIGHTBLUE}light blue {PURPLE}purple {YELLOW}yellow{WHITE}
{INSTANT}This line appears at once.{/INSTANT}
And this one types itself out.
{BOX}
Does it work?
{GREEN}Yes, it works!
No, it's broken...{CHOICE2}

@ZL_TEST_WOOD WOODEN MIDDLE
This is a {RED}wooden{BLACK} sign box.
It closes by itself.{FADE:60}
